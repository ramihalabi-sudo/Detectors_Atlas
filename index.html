Important limitations

For true scheduled checking the project must be published (for example on GitHub Pages with GitHub Actions enabled). Opening index.html as a local file alone cannot read manufacturer sites reliably. The first successful scan establishes a baseline; later scans can detect additions. Scans run on a best-effort schedule, not instantaneously.

Manufacturer coverage and methodology

Each record includes a link to an official maker page or official datasheet. The catalog is a researched starting set, not a promise of every detector worldwide. Availability/export conditions must be confirmed with the manufacturer.

Thermal technology classification: XBn and HFM are specifically named SCD MWIR technologies; InSb, MCT, T2SL, QWIP and uncooled VOx/microbolometer are not relabelled as XBn or HFM. Spectral passbands are model-specific, may refer to filter-defined response, and are not automatically assigned from the generic MWIR/LWIR band. “Not verified” indicates insufficient public model-level evidence.

What the fields mean

Cooling class: Cryogenic (mechanical or JT), TEC (thermoelectric) or Uncooled. Cooler options: combinations explicitly listed by manufacturers; a generic cooler being sold separately is not proof of detector compatibility. Power: detector+cooler configuration values differ from stand-alone cryocooler ratings. MTTF: expected lifetime under maker test/usage assumptions, not a warranty. Unknown fields are deliberately not inferred.

Pixel pitch = center-to-center pixel distance in micrometers; Resolution = physical active array or, for MP-only pages, maker's advertised approximate megapixels; Product type separates an FPA from IDCAs, CMOS chips, complete cameras, and camera cores.

Catalog family only means the manufacturer lists the product but the exact pitch/matrix was not established from the reviewed extract. The app does not fill missing numbers by guessing.

SWIR can include extended SWIR. Some products may cross band boundaries; a dual MWIR/LWIR sensor appears once for each spectral channel with the same official source.
